What the research says

Six findings from the sponsor list and the 70+ winning projects of Cal Hacks 12 (Oct 2025).

1 → 3

One project can win several prizes

Haven won Fetch.ai, YC and LiveKit with one build. Dial won three sponsor prizes. Target 3–4 tracks per project and use each sponsor's required feature visibly.

11

3rd overall used 11 sponsor tools

Project No Cap stacked Bright Data, Claude, Creao, Fetch.ai, Fish Audio, Groq and more. Breadth helped, but each tool did a real job in the demo.

9+

Healthcare agents are saturated

Haven, EDFlow, Elda, CareLink, MedSnap, MemARy, TrialScope and others were all hospital or care agents. Sales-call practice bots won twice. Judges have seen these.

T1

The top logo row is unusual

Anthropic, AWS Trainium (Annapurna), SpacetimeDB and Hyphenate (CFO-office AI). Few teams will build for a finance-ops or real-time-database sponsor, so these tracks may be less crowded.

2026

The big theme is agents with money

Visa, Coinbase (x402), MoonPay, Wajo, CRS and Capital One all sell rails for agents that pay, borrow or verify identity. Trust and safety for those agents is barely served.

2 min

Judging is a 2-minute table pitch

Plus 2 minutes of Q&A. Criteria: real-world application, working quality, creativity, technical complexity. Submission needs GitHub, an image, table number and a demo video.

Prep plan, now through Oct 23

The rules allow ideation before the event but no project implementation. Accounts, API keys, sandbox requests and throwaway tutorials are fine. Project code starts Friday night.

Request access this week

    Ticks are saved in your browser only.

    Learn in throwaway repos

    • Claude Agent SDK: one agent, one custom tool, one MCP server.
    • Fetch.ai: register a hello-world uAgent with the chat protocol on Agentverse.
    • SpacetimeDB: TypeScript module + React client quickstart, deploy once.
    • Cartesia Line: a voice agent you can phone.
    • Elastic Agent Builder: expose one tool over MCP.
    • Bright Data or Apify via MCP from Claude.
    • Delete the repos afterwards. Nothing carries into the event.

    Roles for three

    • Agent / backend lead: agent loop, tools, sponsor SDKs, data model.
    • Demo / frontend lead: the screen judges see, the live "jaw-drop" moment, polish.
    • Integrations + pitch lead: track requirements checklist, sponsor booths, README, video, Devpost write-up.
    • Everyone codes; the roles decide who owns each deliverable.

    36-hour clock (CH12 schedule)

    Skills and plugins to use

    • adhd (used for this pool): rerun with the real track list on Friday for fresh ideas.
    • engineering:system-design and engineering:architecture: architecture and decision record in hour one.
    • mattpocock-skills:grilling: stress-test the chosen idea before committing.
    • claude-mem:make-plan → claude-mem:do: phased build plan executed with subagents during the event.
    • anthropic-skills:deep-research: digest a sponsor's docs fast once tracks drop.
    • Worth installing: Anthropic's frontend-design and Design plugins for UI polish.

    Pitch checklist

    • Open with the live moment, not the problem slide.
    • Name each sponsor's tech on screen as it runs.
    • One sentence on why this exists now (2026 agent payments, etc.).
    • Have a recorded fallback if Wi-Fi or an API dies.
    • Prepare answers for "what's the business?" (YC, a16z, Llama Ventures judge that).
