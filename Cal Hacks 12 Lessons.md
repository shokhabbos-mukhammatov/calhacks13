# Cal Hacks 12 lessons (Oct 2025)

- One project can win several prizes: Haven won Fetch.ai + YC + LiveKit.
- 3rd overall (Project No Cap) used 11 sponsor tools, each doing a real job in the demo.
- 9+ winners were healthcare or care agents; 2 were sales-call practice bots. Avoid both.
- Judging: 2-minute table pitch + 2-minute Q&A. Criteria: application, quality, creativity, technical complexity.
- Submission needs GitHub, an image, table number and a demo video.
